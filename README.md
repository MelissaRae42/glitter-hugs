# Glitter Hugs

A WoW add-on to facilitate the art of hugging...

Glitter Hugs is a standalone addon for **World of Warcraft: Forever**. The pink heart on the badge sends a hug to a nearby friendly player, and the badge counts your hugs for the day. Left-click the minimap heart for your daily graph and log. Right-click it for settings.

## Install v0.3.1

1. Download this repository as a ZIP using **Code → Download ZIP**.
2. Extract it and copy the inner `GlitterHugs` folder into `World of Warcraft/_forever_/Interface/AddOns/`.
3. Enable **Glitter Hugs** in the game's AddOns list.

See [the addon guide](GlitterHugs/README.txt) for commands, settings, and the optional action bar macro.
